Bootstrap na prática

Cinco exemplos curtos que mostram como o framework funciona: classes CSS, atributos data-bs-*, API JavaScript e temas. Nenhum deles usa Virtual DOM ou build de aplicação.

1. Grid responsivo (mobile-first)

Redimensione a janela. Sem prefixo, a coluna ocupa 12 de 12; a partir de md são duas por linha; a partir de lg, três.
